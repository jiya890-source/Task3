# Candidate Technical Assessment System

A dynamic web application for conducting technical assessments and shortlisting candidates.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- JSON

## Features

- Multiple programming language selection
- JavaScript, Python, Java and C++ questions
- Multiple-choice technical assessment
- Previous and Next navigation
- Progress bar
- Automatic score calculation
- 70% qualification threshold
- Conditional resume upload
- PDF, DOC and DOCX validation
- Maximum 5 MB resume size
- Responsive mobile design
- Error handling

## How to Run

1. Install XAMPP.
2. Start Apache.
3. Copy the Task3 folder into:

C:\xampp\htdocs\

4. Open the application in your browser:

http://localhost/Task3/

## Project Structure

- index.html - Main application interface
- style.css - Styling and responsive design
- script.js - Quiz logic and validation
- questions.json - Question bank
- upload.php - Resume upload handling
- README.md - Project documentation

## Question Bank

The application contains 10 questions for each language:

- JavaScript
- Python
- Java
- C++

## Resume Upload

Candidates who score 70% or above can upload their resume.

Allowed formats:

- PDF
- DOC
- DOCX

Maximum file size: 5 MB.
